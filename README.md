# SWYNEX Data Cleaning & Preparation

## About the Project
This project was completed as part of SWYNEX Internship Task 1.
The objective was to clean and prepare a student dataset for analysis.

## Dataset
The dataset contains student academic and attendance-related information.

## Data Cleaning Performed
- Checked for duplicate records
- No duplicate records were found
- Checked all columns for missing values
- Removed the completely empty `assignments_submitted` column
- Checked data values and formats for consistency
- Prepared the cleaned dataset for analysis

## Tools Used
- Microsoft Excel
